BROWSER ASSISTANT · MANIFEST V3

安装后直接使用，无需注册账号

插件内置本机工作台，可录入档案、优化原 Word 内容、转换图片 PDF 并辅助填表。不需要 ChatGPT 或 GitHub 账号；云端和模型服务为可选功能。

已识别当前环境正在检测…下载适配安装包
正式支持

Chrome

下载解压后，在扩展程序页开启开发者模式并“加载已解压的扩展程序”。应用商店版需完成[Chrome 商店审核]后切换为一键添加。

正式支持

Microsoft Edge

兼容同一 Manifest V3 包。在 edge://extensions 打开开发人员模式后加载文件夹；后续可发布到[Edge 加载项商店]。

兼容模式

QQ 浏览器

仅支持可加载 Chromium 扩展的桌面版本。若当前版本没有扩展管理入口，请改用 Chrome 或 Edge。

能力检测

夸克浏览器

桌面版仅在当前版本支持扩展中心或加载本地扩展时可用；手机夸克不能运行本桌面扩展，可直接使用移动工作台。

跟着页面完成连接

1
下载并解压

点击上方按钮，解压到一个不会被误删的文件夹，例如[文档/简投浏览器助手]。不要直接双击压缩包内文件。

2
打开扩展管理页

Chrome 输入 chrome://extensions；开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的 extension 文件夹。

3
打开本机工作台

点击插件图标，再点击“无需账号 · 打开本机工作台”。首次使用不需要服务地址或扫码。

4
编辑档案并选择填表版本

录入真实档案，按需要生成岗位版本，然后点击“用于本机填表”。每次修改档案后重新选择。

5
打开招聘表单并确认填写

进入申请页，点击插件中的“识别并填写当前页面”，检查绿色标记和缺失提示。附件、验证码、声明和最终提交由本人完成。企业自定义表单可能需要手填。

这是 ZIP 手动安装流程，需要下载、解压、开启开发者模式并选择文件夹。QQ、夸克尚未真机验证；是否可用取决于具体版本是否允许加载桌面扩展。

扩展不会读取微信聊天记录，也不会保存招聘网站密码。设备令牌可在[简投工作台 → 在线填表 → 已连接设备]随时撤销。
