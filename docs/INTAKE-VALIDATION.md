# v1.2 简历导入与图片 JD 验收

## 实现范围

- DOCX 和文本 PDF 提取；低文字量 PDF 页转图并本机 OCR。中英文引擎、Worker、WASM 与字库随静态资源及扩展包分发。
- 主档案字段与原文依据一起展示，已有值默认保留。未归类内容保留给用户复核，读取失败不修改主档案。
- 图片 JD 实际 OCR，核对后才替换原 JD。
- 上传 DOCX 同时复用原格式编辑对象。
- 主档案生成的岗位版接通深度改写服务，改写结果进入预览与 DOCX 导出，不覆盖主档案。
- 采购相关关键词参与匹配和已有经历排序。

## 已验证

使用合成文件验证 DOCX 字段提取、文本 PDF 读取、中英文图片实际 OCR、扫描 PDF 实际 OCR、已有数据不覆盖和坏文件处理。深度改写使用模拟模型响应测试主档案隔离与导出流程，不视为真实模型质量通过。

另在本地用用户提供的中文原简历验证，提取 30 项建议字段；姓名、最高学历学校、本科学校、邮箱、采购项目与行政实习角色六项对应检查通过，2 行未归类内容保留待核对。此结果仅针对该样本，不是整体识别准确率；真实个人信息与文件不进入公开仓库。

## 已知边界

旧 DOC 需另存 DOCX。PDF 最多 20 页，扫描识别最多 5 页；混合页若已有较多文字，图片中的额外文字不保证被识别。多栏/浮动文本框的阅读顺序、跨页经历、日期和不同语言字段都需用户最终核对。

Word 兼容性分支采用单一读取视图，但不再删除源文档的备用表示。分支中的复杂段落保留原文，避免破坏原格式导出。

深度模型未配置时仍不可用；不存在已验证的筛选通过率提升承诺。全文事实变更的交互确认和实际排版渲染验收仍未完整实现，不能将分析文档中的要求说成已上线能力。
