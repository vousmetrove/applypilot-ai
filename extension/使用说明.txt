简投 ApplyPilot 浏览器助手 1.0

支持范围
- Chrome、Microsoft Edge：正式支持 Manifest V3。
- QQ 浏览器、夸克桌面版：仅在当前版本提供 Chromium 扩展管理/本地加载能力时可用。
- 手机浏览器不能运行本桌面扩展；手机用于扫码授权和查看进度。

安装
1. 解压本安装包。
2. 在浏览器扩展管理页开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中 extension 文件夹。
4. 固定“简投”图标到工具栏。

首次连接
1. 点击“简投”图标，填写部署者提供的 HTTPS 服务地址并授权该域名。
2. 点击“生成手机连接二维码”。
3. 用手机微信扫码，登录简投后点击“确认连接这台电脑”。
4. 回到电脑，扩展会自动同步主档案。二维码十分钟过期且只能授权本次设备。

填表
1. 打开飞书招聘、Moka 或其他招聘申请表。
2. 点击扩展中的“识别并填写当前页面”。
3. 检查绿色标记和缺失必填项。
4. 附件、证件号码、验证码、承诺声明与最终提交必须本人处理。

受控远程任务
- 手机端只能创建“同步档案、打开申请页、分析当前表单、填写当前表单”四类任务。
- 除同步档案外，电脑端都必须再次点击“执行”。
- 本扩展不包含远程桌面、远程命令行、密码读取或静默提交能力。

撤销
- 在简投工作台“在线填表 → 已连接设备”撤销，或在扩展中点击“断开当前设备”。
